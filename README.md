# Depikt

**Turn rough ideas into production-ready prompts for ChatGPT Images 2.5.**

Depikt is a free prompt tool for modern AI image generation. Type a rough idea — “poster for a coffee brand” — and get back a structured, copy-ready prompt tuned for ChatGPT Images 2.5 and GPT-Image-2.5 workflows. No account required.

**Live at [depikt.app](https://depikt.app)**

## What you can do

### Generate prompts
Paste a rough idea and Depikt builds a polished prompt with the details that actually control the result: composition, hierarchy, lighting, materials, typography, aspect ratio, preservation constraints, and style direction.

### Work with Images 2.5 strengths
The prompt engine is tuned around the newer image model’s strongest workflows:
- reference-image fidelity;
- focused edits that preserve everything else;
- multi-turn edit consistency;
- complex layouts and presentation-style visuals;
- transparent-background assets;
- stronger style, texture, and lighting control.

### Browse 500 curated prompts
A library of production-grade prompts across 10 categories, each with an example thumbnail showing what it produces. Copy any prompt directly or remix it into something new.

### Critique existing prompts
Paste any prompt and get a 1–10 score, specific weaknesses, and a complete rewritten version with the improvements applied.

### Use reference images
Upload or drag in an image. Depikt can treat it as a style reference, subject/identity reference, current-state edit source, or rough layout guide depending on the request.

### Save favorites and history
Favorite prompts locally and restore previous generations from browser history storage. No account required.

### Open in Imago
Generated prompts can be taken into Imago, a custom GPT focused on actually creating and editing images.

## How it works

1. You type a rough idea
2. Depikt classifies it into one of 10 visual categories
3. It applies a category-specific structure tuned for the request
4. It adds preservation, layout, text, edit, or reference-image constraints when needed
5. You get a polished prompt ready for ChatGPT Images 2.5 or an OpenAI image-generation workflow

## Prompt categories

- Cinematic Scene
- Poster / Cover
- Infographic / Diagram
- UI Mockup
- Social Post / Ad
- Storyboard / Multi-panel
- Interior / Food / Fashion / Product
- Visual Summary
- Image Edit
- Open-Ended Creative
